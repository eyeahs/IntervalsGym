IntervalsGym 개인정보처리방침

시행일: 2026년 6월 24일

IntervalsGym은 사용자가 러닝 및 웨이트 트레이닝 Routine을 확인하고, 운동 수행 기록을 로컬에 저장하며, 사용자가 선택한 경우 Intervals.icu 계정과 동기화할 수 있도록 돕는 Android 앱입니다. 이 문서는 IntervalsGym이 어떤 정보를 처리하고, 어디에 저장하며, 언제 외부 서비스로 전송하는지 설명합니다.

IntervalsGym은 별도의 자체 서버를 운영하지 않습니다. 대부분의 데이터는 사용자의 기기 안에 저장되며, Intervals.icu 로그인 및 업로드 기능을 사용한 경우에만 Intervals.icu로 전송됩니다.

1. 처리하는 정보

앱 기능 제공을 위해 다음 정보를 처리할 수 있습니다.

  • 운동 Routine: 웨이트 트레이닝 routine, 러닝 routine, 운동 이름, 세트, 반복 횟수, 무게, 휴식 시간, 러닝 블록 정보
  • 운동 수행 기록: 운동 시작/종료 시간, 완료한 세트, 실제 수행 순서, 실제 휴식 시간, 러닝 수행 블록, 예상 거리
  • Intervals.icu 연동 정보: 사용자가 입력한 Intervals.icu API Key, Intervals.icu에서 내려받은 Routine 및 결과 데이터, 업로드 상태
  • 심박계 연결 정보: Bluetooth 심박계 검색 및 연결을 위한 기기 이름, 기기 주소, 실시간 심박수
  • 앱 상태 정보: 진행 중 운동, 휴식 타이머, 러닝 타이머, 화면 표시 상태 등 앱 사용을 이어가기 위한 로컬 상태

2. 정보의 이용 목적

  • 운동 Routine 생성, 수정, 수행 및 기록 저장
  • 운동 중 휴식 타이머, 러닝 블록 타이머, 플로팅 UI 및 알림 표시
  • Intervals.icu에서 훈련 일정과 결과를 가져오거나, 사용자가 요청한 운동 기록 및 Routine을 업로드
  • Bluetooth 심박계 연결, 현재 심박 표시, 짧은 실시간 심박 그래프 표시
  • 앱 재시작 또는 화면 회전 후에도 진행 중인 운동 상태 복원

3. 저장 위치와 보관

  • 운동 Routine, 운동 기록, 진행 중 운동 상태, Intervals.icu API Key는 사용자의 기기 내 앱 저장소에 저장됩니다.
  • 심박수 샘플은 실시간 표시를 위해 앱 실행 중 메모리에 일시적으로 보관되며, 현재 버전에서는 운동 기록으로 영구 저장하지 않습니다.
  • Android 시스템 백업 설정에 따라 앱 데이터가 사용자의 Google 계정 백업에 포함될 수 있습니다. 이는 Android 기기 설정에 의해 관리됩니다.
  • 사용자는 앱의 Intervals 로그아웃 기능, 앱 데이터 삭제, 또는 앱 삭제를 통해 기기에 저장된 데이터를 삭제할 수 있습니다.

4. 제3자 제공 및 외부 전송

IntervalsGym은 자체 서버로 데이터를 전송하지 않습니다. 다음 경우 외부 서비스와 통신합니다.

  • Intervals.icu: 사용자가 API Key를 입력하고 동기화 또는 업로드 기능을 사용할 때, Intervals.icu API를 통해 훈련 Routine, 운동 결과, 운동 설명, 운동 시간, 거리, 웨이트 볼륨, training load 등의 데이터가 전송되거나 내려받아질 수 있습니다.
  • Bluetooth 심박계: 사용자가 심박계 연결 기능을 사용할 때 주변 Bluetooth Low Energy 심박계를 검색하고 연결합니다. 이 과정의 데이터는 심박계와 기기 사이에서 처리되며 IntervalsGym의 자체 서버로 전송되지 않습니다.

Intervals.icu에서 처리되는 데이터에는 Intervals.icu의 개인정보처리방침 및 계정 설정이 적용됩니다.

5. Android 권한 사용

  • 인터넷: Intervals.icu API와 통신하기 위해 사용합니다.
  • Bluetooth 검색 및 연결: 사용자가 선택한 심박계를 찾고 연결하기 위해 사용합니다. 위치 추적 목적으로 사용하지 않습니다.
  • 알림 및 진동: 휴식 타이머 또는 러닝 블록 종료 알림을 제공하기 위해 사용합니다.
  • 다른 앱 위에 표시: 운동 중 앱을 벗어난 경우 작은 플로팅 타이머 UI를 보여주기 위해 사용합니다.

6. 광고, 추적 및 판매

  • IntervalsGym은 광고 SDK를 포함하지 않습니다.
  • IntervalsGym은 사용자의 개인정보를 판매하지 않습니다.
  • IntervalsGym은 광고 목적의 사용자 추적을 하지 않습니다.

7. 아동 개인정보

IntervalsGym은 아동을 대상으로 설계된 앱이 아니며, 고의로 아동의 개인정보를 수집하지 않습니다.

8. 사용자의 선택 및 삭제

  • Intervals.icu 연동을 원하지 않는 경우 로그인 없이 로컬 기록 기능만 사용할 수 있습니다.
  • Intervals.icu API Key는 앱의 Intervals 로그아웃 기능으로 삭제할 수 있습니다.
  • 기기 내 모든 앱 데이터는 Android 설정의 앱 정보에서 저장공간을 삭제하거나 앱을 제거하여 삭제할 수 있습니다.
  • Intervals.icu에 이미 업로드된 데이터의 수정 또는 삭제는 Intervals.icu 서비스 안에서 관리할 수 있습니다.

9. 보안

IntervalsGym은 기기 내 앱 저장소를 사용하여 로컬 데이터를 보관하고, Intervals.icu와 통신할 때 HTTPS를 사용합니다. 다만 사용자의 기기 보안 상태, Android 백업 설정, Intervals.icu 계정 보안은 사용자와 각 서비스 제공자의 관리 범위에 속합니다.

10. 변경

이 개인정보처리방침은 앱 기능 변경 또는 법적 요구사항에 따라 업데이트될 수 있습니다. 중요한 변경이 있는 경우 이 페이지의 시행일을 갱신합니다.
